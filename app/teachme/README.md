# Teach Me Mode

Teach Me is deliberately human-in-the-loop.

FixPilot can:
- explain the next action
- show why the action matters
- identify the UI area to use
- display the current cursor coordinates
- track tutorial progress

FixPilot does not:
- move the mouse
- click
- type
- send keyboard input
- launch arbitrary programs
- execute repair commands

This creates a safe foundation for future guided-computer interaction.
